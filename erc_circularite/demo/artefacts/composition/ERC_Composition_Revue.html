De quoi est faite chaque pièce

La chaîne propose une classe matière pour chaque pièce de la nomenclature, avec ce qu'elle en sait. Vous tranchez les cas qu'elle n'a pas su résoudre et vous contrôlez par sondage ceux qu'elle a acceptés seule. Vos décisions deviennent la référence : elles corrigent les pièces, servent d'exemples aux pièces voisines et mesurent ce que vaut chaque source.

    Enregistrer vos décisions

    Cette page ne modifie rien toute seule. Elle prépare un fichier que la chaîne relit au passage suivant.

    1. Indiquez votre nom : il est gardé avec chaque validation.
    2. Téléchargez le fichier et déposez-le dans le dossier Acquisition du projet, sous le nom .
    3. Relancez la chaîne (python -m erc.composition, ou le carnet 07). Les validations déjà relues restent dans la base : le fichier peut ne contenir que les nouvelles.

    Si le téléchargement ne démarre pas (page ouverte dans un lecteur qui le bloque), copiez le contenu et collez-le dans un fichier de ce nom.

    Ce que valent les sources

    Chaque type de source a une fiabilité de départ, posée par bon sens et de faible poids. Elle est remplacée par ce qui est observé sur les pièces validées : combien de fois la source a eu raison.

    Ce qu'a coûté la recherche

    Une mesure faite seulement sur les pièces douteuses sous-estime les sources, puisque ce sont justement les cas où elles se contredisent. Le contrôle par sondage des pièces que la chaîne ne vous montre pas (acceptées, ou laissées faute d'enjeu) corrige ce biais : c'est la raison d'être de la file « Sondage ».
